# 球体近似

## 半径 4 分层思路
- `y=0`：最大环。
- `y=±1`：次大环。
- `y=±2`：中环。
- `y=±3`：小环。
- `y=±4`：顶点。

## 示例（节选）
```json
[
  {"type":"points","block":"shell","at":[[4,0,0],[0,0,4],[-4,0,0],[0,0,-4]]},
  {"type":"points","block":"shell","at":[[3,1,0],[0,1,3],[-3,1,0],[0,1,-3],[3,-1,0],[0,-1,3],[-3,-1,0],[0,-1,-3]]},
  {"type":"points","block":"shell","at":[[0,4,0],[0,-4,0]]}
]
```
