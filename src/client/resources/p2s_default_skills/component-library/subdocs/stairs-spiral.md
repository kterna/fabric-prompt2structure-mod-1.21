# 螺旋楼梯

## 局部模板
```json
[
  {"type":"line","block":"core","from":[0,0,0],"to":[0,6,0]},
  {"type":"points","block":"step","at":[[1,0,0],[1,1,1],[0,2,1],[-1,3,1],[-1,4,0],[-1,5,-1],[0,6,-1]]}
]
```

## 说明
- 适合半径 1-2 的紧凑楼梯。
- 扩大半径时，把 `points` 沿环向外推并增加层级点。
