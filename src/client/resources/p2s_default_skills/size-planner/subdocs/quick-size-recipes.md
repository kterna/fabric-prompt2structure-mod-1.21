# 尺寸速查

## 住宅类
- 小屋：占地 `9x9`，`1-2` 层，层高 `4-5`
- 联排住宅：占地 `13x11`，`2-3` 层，层高 `5-6`
- 别墅：占地 `17x13`，`2-3` 层，层高 `5-7`
- 庭院宅：占地 `21x17`，`1-2` 层，中庭留白 `5x5` 或以上

## 商业类
- 小商铺：占地 `11x9`，`1-2` 层，首层净高 `5-6`
- 餐馆：占地 `15x11`，`1-2` 层，用餐区净高 `5-7`
- 旅馆：占地 `19x13`，`3-4` 层，标准层净高 `4-5`

## 公共建筑类
- 村庄大厅：占地 `23x17`，`1-2` 层，主厅净高 `7-10`
- 教堂/神殿：占地 `27x17`，`2-3` 层，中殿净高 `10-14`
- 图书馆：占地 `21x15`，`2-4` 层，书库层净高 `5-6`

## 防御与纪念类
- 城堡主塔：基底 `9x9`，高度 `18-30`
- 城墙段：厚 `2`，高 `8-12`，塔楼间距 `12-20`
- 纪念碑：基底 `7x7`，高度 `14-24`

## 景观与附属
- 凉亭：占地 `7x7` 或 `9x9`，高度 `5-8`
- 仓库：占地 `11x9`，高度 `6-9`
- 温室：占地 `13x9`，高度 `6-8`

## 快速换算
- 若超出边界：优先按 `0.85` 或 `0.7` 系数同比缩放。
- 若需要更高层高：先减少层数，再抬高净高。
- 若需要更大占地：优先横向扩展，再补纵向层数。
