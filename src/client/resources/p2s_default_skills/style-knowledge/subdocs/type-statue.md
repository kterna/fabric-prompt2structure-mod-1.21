# 雕像/雕塑

## 体量特征
- 非建筑！不造房间/墙壁/屋顶
- 体素化思维：将复杂形状分解为球体、椭球、圆柱组合
- 轮廓优先：大形 -> 小形 -> 细节

## 人物比例
- 头部约占身高 1/7~1/8
- 肩宽约 2 个头宽
- 腿长约占身高 1/2
- 构建顺序: 躯干 -> 头部 -> 四肢 -> 手脚 -> 面部 -> 装备

## 细节技巧
- 面部: 眼睛用黑色方块、鼻子/嘴用台阶
- 衣褶/鳞片: 用楼梯方块表现
- 毛发/羽毛: 用羊毛或树叶层层叠加
- 雕像需要底座，底座比雕像宽

## 材料倾向
| 用途 | 方块 |
|------|------|
| 白石像 | smooth_quartz, sandstone |
| 灰石像 | stone, andesite |
| 铜像 | copper_block, oxidized_copper |
| 金像 | gold_block |
| 黑石像 | blackstone, obsidian |
| 细节 | 各种 stairs 和 slab |

## 动作偏好
- points 逐层轮廓点 + line 四肢骨架 + box:solid 躯干核心
