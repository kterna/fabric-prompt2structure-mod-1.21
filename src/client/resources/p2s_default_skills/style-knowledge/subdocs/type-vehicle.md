# 载具/机械

## 体量特征
- 有明确方向性（前后、上下）和功能性（动力、驾驶舱）
- 流线型用楼梯和台阶渐变过渡
- 类型: 帆船/海盗船、轿车/卡车、客机/战斗机、蒸汽火车、飞船/机甲

## 各类要点
- 船只: 前尖后宽流线船体、楼梯做船舷曲线、龙骨为核心
- 汽车: 低矮车身、四轮、前后玻璃与车灯
- 飞机: 圆柱机身、后掠翼用台阶做薄、发动机为圆柱
- 火车: 蒸汽锅炉（圆柱）、烟囱、连杆、轨道用铁轨方块
- 机甲/飞船: 关节可动感、发光部件、驾驶舱
